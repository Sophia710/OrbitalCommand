# 商机分析数字员工 — 交接文档

## 项目概况

基于卫星通信/AEROS 领域的数字员工管理平台，前端使用 Vue 3 + Vite 构建。当前重点开发「商机分析数字员工」（市场商机分析员）的相关功能，包括标讯汇聚、标讯分析、领域专业化配置等工具面板，以及任务发布页面的交互优化。

## 技术架构要点

### 面板组件模式
所有工具面板（标讯汇聚/标讯分析/领域专业化配置/数据源管理）遵循相同的模式：
- 组件文件放在 `src/components/tools/` 目录
- 在 `ChatOverlay.vue` 中通过 `activePanel` 状态（`ref('')`）控制显隐
- 工具箱按钮点击设置 `activePanel` 值，面板点击返回按钮重置为 `''`
- 面板渲染使用 `<component :is="...">` 或直接 `v-if` 条件渲染

### 状态管理
- 使用 Vue 3 Composition API（`ref`, `computed`, `watch`）
- 聊天状态在 `stores/chat.js`（Pinia store）
- 数字员工数据使用 API 层 mock（`src/api/` 目录下）

### 样式系统
- CSS 变量定义在 `src/styles/variables.css`
- 深色主题为主，支持 `data-theme='light'` 浅色主题
- 玻璃态效果（`--surface` 半透明 + `--glass-blur` 模糊）
- 紫色主色调（`--accent: #8b5cf6`）

## 踩过的坑（勿再踩）

### 1. `SearchReplace` 工具的文件内容同步问题
- **问题**：多次编辑同一文件后，`SearchReplace` 因文件内容与缓存不一致报错 `search content not found`
- **解决**：每次编辑前先用 `Read` 工具读取最新内容
- **教训**：连续编辑同一文件时，务必重新读取最新内容再执行替换

### 2. 面板组件切换时函数未定义
- **问题**：移除 `v-if="isMarketRadar"` 条件后，`openKnowledgeDrawer` 函数从未定义，导致点击按钮知识库抽屉不显示
- **解决**：补全所有引用的函数定义
- **教训**：移除条件渲染后，确保所有引用的变量/函数在所有分支都有定义

### 3. 欢迎页被意外删除
- **问题**：布局重构时，欢迎页（`chat-welcome`）模板和 CSS 被错误删除，导致新建会话后无居中页面
- **解决**：重新恢复完整的欢迎页模板和 CSS
- **教训**：编辑大型文件时，先确认要修改的代码段范围，不要在同一个 `SearchReplace` 操作中同时修改不相邻的多个代码块

### 4. 工具箱按钮顺序
- **问题**：用户要求调整工具箱按钮顺序，但顺序依赖模板中的 DOM 顺序
- **解决**：直接调整模板中按钮的 HTML 顺序
- **教训**：按钮顺序由 DOM 顺序决定，修改模板即可
